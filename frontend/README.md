# Frontend (Phase 1b) - Next.js skeleton

This folder contains a minimal Next.js App Router skeleton with basic Test Library, Test detail, Listening and Reading pages.

Run (requires Node 18+):

```bash
cd frontend
npm install
npm run dev
```

The frontend expects the backend to be running at `http://localhost:8000` and to expose the API routes implemented in `backend/app/main.py`.
